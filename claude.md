# Pokefiche

## Stack
HTML5 / CSS3 / JS ES6 vanilla, aucune dépendance externe.
Déployé sur GitHub Pages.

## Structure des fichiers
- index.html — point d'entrée
- style.css — feuille de style
- js/ — modules ES6, un fichier par responsabilité
- data/ — catalogue.json
- tools/forgecat/ — parser Python, indépendant du site

## Conventions
- Commentaires en français
- snake_case pour les fichiers JS
- Aucune variable globale
